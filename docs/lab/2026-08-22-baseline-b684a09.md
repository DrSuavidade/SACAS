## Experiment policy from here

1. One hypothesis per commit (e.g., "raise goal-rank cutoff floor to 5").
2. Rerun `python -m sacas lab histbench --format json`; compare macro P/R/F1
   **and total admitted-context tokens**, never F1 alone.
3. Accept changes that improve F1 at equal or lower tokens, or hold F1 with a
   clear token reduction.
4. Weak-gold retrieval metrics are a proxy. Once a change survives here,
   validate against real coding-agent outcomes before treating it as progress.

## Known harness caveat

On Windows, worktree teardown can intermittently fail with `WinError 32`
(transient file lock). Such errors are infrastructure noise, not routing
failures; rerun before recording.
